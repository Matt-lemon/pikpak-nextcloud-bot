## 🤔 이게 뭔가요?

**PikPak처럼 쓰는 내꺼 클라우드 다운로더**

- 평소: 토렌트 자석링크 `magnet:?xt=...` 있으면 토렌트 프로그램 켜고 다운로드하고...
- 이제: **텔레그램에 링크만 던지면** NAS가 알아서 다운받고 Nextcloud에 저장해줌!

예시:
```
내가 텔레그램에: magnet:?xt=urn:btih:abc...  (전송)
봇이: ✅ 완료! https://mir2mix.asuscomm.com/s/xxxx (링크줌)
```
끝! Nextcloud 들어가면 파일 있음!

1.  **우분투 NAS** - 이미 있음 (mir2mix.asuscomm.com)

3.  **5분 시간**

## STEP 0: NAS에 접속하기

NAS에 직접 키보드 연결하거나, 다른 컴퓨터에서 접속:

**Windows면:**
- PuTTY 프로그램 설치 또는
- PowerShell 열고 `ssh 아이디@NAS_IP` 입력

**Mac이면:**
- 터미널 열고 `ssh 아이디@NAS_IP`

> NAS IP 모르면 공유기 설정에서 확인하거나, `mir2mix.asuscomm.com`이 NAS 주소니까 같은 네트워크면 NAS 내부 IP로 접속

성공하면 이런 화면:
```
username@nas:~$
```

## STEP 1: 텔레그램 봇 만들기 (1분)

핸드폰에서 텔레그램 열기

1.  검색창에 `@BotFather` 입력 → 제일 위에 파란 체크 있는 봇 클릭
2.  `/newbot` 이라고 보내기
3.  봇 이름 물어봄 → `내 PikPak 봇` 이라고 보내기 (아무거나)
4.  봇 아이디 물어봄 → `mir2mix_pikpak_bot` 이라고 보내기
    - **꼭 _bot으로 끝나야 함!** 이미 있으면 `mir2mix_pikpak_123_bot` 처럼 숫자 추가
5.  그러면 긴 토큰 줌:
    ```
    1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
    ```
    **이거 복사!** 메모장에 저장! 이게 봇 비밀번호!

> 실패하면? 아이디가 이미 있는거. 다른 이름으로 다시 시도

---

## STEP 2: Nextcloud 앱 비밀번호 만들기 (1분)

이거 제일 중요! 일반 비번 쓰면 안됨!

1.  컴퓨터 인터넷에서 `https://mir2mix.asuscomm.com` 접속 → 로그인
2.  오른쪽 위 동그란 프로필 사진 클릭 → **설정** 클릭
3.  왼쪽 메뉴에서 **보안** 클릭
4.  맨 아래로 스크롤 → **앱 비밀번호** 또는 **기기 및 세션** 섹션 찾기
5.  앱 이름에 `PikPakBot` 입력 → **새 앱 비밀번호 생성** 클릭
6.  이런 비번 나옴: `abcd-efgh-ijkl-mnop-qr` 
    **이거 복사!** 이게 진짜 비밀번호! 공백 포함해서 복사

> 왜 앱 비밀번호? 해킹 방지! 일반 비번 털려도 앱 비번은 따로라 안전

## STEP 3: 프로그램 다운로드 (30초)

NAS 터미널에서 (STEP 0에서 접속한 그 검은 화면):

```bash
# 홈으로 이동
cd ~

# 기존에 있으면 삭제
rm -rf pikpak-nextcloud-bot

# 다운로드 (복사해서 붙여넣기)
git clone https://github.com/Matt-lemon/pikpak-nextcloud-bot.git

# 폴더 들어가기
cd pikpak-nextcloud-bot

# 파일 목록 보기
ls
```

`README.md` 같은 파일들 보이면 성공!

> `git: command not found` 에러나면:
> ```bash
> sudo apt update && sudo apt install git -y
> ```

## STEP 4: 설정 파일 작성 (1분) - 제일 중요!

```bash
# 설정 파일 복사
cp .env.mir2mix .env

# 설정 파일 열기
nano .env
```

그러면 이런 파일 열림:

```
TELEGRAM_BOT_TOKEN=여기에_봇토큰_입력
NEXTCLOUD_USERNAME=여기에_Nextcloud_아이디
NEXTCLOUD_PASSWORD=여기에_앱비밀번호
...
```

**키보드로 수정:**

1.  `TELEGRAM_BOT_TOKEN=여기에_봇토큰_입력` → `여기에_봇토큰_입력` 지우고 STEP 1에서 복사한 토큰 붙여넣기
    - 예: `TELEGRAM_BOT_TOKEN=1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`

2.  `NEXTCLOUD_USERNAME=여기에_Nextcloud_아이디` → 내 Nextcloud 로그인 아이디
    - 예: `NEXTCLOUD_USERNAME=admin` 또는 `NEXTCLOUD_USERNAME=matt`

3.  `NEXTCLOUD_PASSWORD=여기에_앱비밀번호` → STEP 2에서 복사한 앱 비밀번호
    - 예: `NEXTCLOUD_PASSWORD=abcd-efgh-ijkl-mnop`

**저장하기:**
- `Ctrl + O` 누르기 → `Enter` 누르기 → `Ctrl + X` 누르기 (나가기)

> 붙여넣기 안되면? 마우스 오른쪽 클릭 → Paste 또는 `Ctrl+Shift+V`

## STEP 6: 실행! (10초)

```bash
# 실행!
docker compose -f docker-compose.ubuntu.yml up -d --build
```

`--build`는 처음에만 필요. 다음부터는 `up -d`만 하면 됨.

기다리면 (1~2분) 다운로드 됨.

로그 확인:

```bash
docker compose -f docker-compose.ubuntu.yml logs -f bot
```

이런 글자 나오면 성공:

```
🚀 PikPak Clone Bot 시작!
Nextcloud: https://mir2mix.asuscomm.com -> /PikPakBot
```

끄려면 `Ctrl + C`

## 😭 안될때 해결법

**Q: 봇이 답이 없어요**
- `docker compose -f docker-compose.ubuntu.yml logs -f bot` → 에러 확인
- `TELEGRAM_BOT_TOKEN` 맞는지 `nano .env`로 확인
- 봇이 꺼져있을수도: `docker compose -f docker-compose.ubuntu.yml up -d`

**Q: Nextcloud 업로드 실패**
- `python3 test_nextcloud.py` 다시 실행
- 앱 비밀번호 맞는지 확인 (일반 비번 아님!)
- Nextcloud 용량 확인: `https://mir2mix.asuscomm.com/settings/user`

**Q: 토렌트 다운로드가 0%에서 멈춤**
- 자석링크는 처음에 1~2분 걸림 (사람 찾는중)
- 공유기에서 6888 포트 포워딩 필요할 수도
- 그래도 안되면 자석링크가 죽은거. 다른 링크로 시도

**Q: 유튜브 다운로드 실패**
```bash
docker exec pikpak-bot pip install -U yt-dlp
docker compose -f docker-compose.ubuntu.yml restart bot
```

**Q: .env 수정했는데 적용 안됨**
```bash
docker compose -f docker-compose.ubuntu.yml down
docker compose -f docker-compose.ubuntu.yml up -d --build
```
